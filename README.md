# 臺灣政治人物關係圖譜（Taiwan Political Network）

固定網址：https://eva20011023-stack.github.io/taiwan-political-network/

這是一份持續擴充的、依公開來源整理的政治人物關係資料庫。現在整合維基百科〈新黨〉、〈張榮味〉、〈王鴻薇〉、〈吳崢〉、〈王建煊〉、〈九月政爭〉、〈管碧玲〉、〈TVBS戰情室〉、〈陳為廷〉、〈監聽國會事件〉、〈柯建銘〉、〈最高法院檢察署特別偵查組〉。

## 使用方式

- 首頁提供「關係導向（力導向）」與「黨籍群集（力導向）」兩種排列。
- 顏色代表資料庫中有來源的**最近紀錄／歷史政黨歸屬**，不代表即時、現存黨籍或政治立場。
- 可以依黨籍篩選，也能只看已知不同黨籍標籤間的直接連線；跨黨線可能跨不同歷史年代。
- 點擊節點或人物名稱會**自動取消黨籍／跨黨篩選、顯示完整網絡、重設視角**，並以人物資料視窗提供關係類型、年份與來源。資料視窗中的其他人名也可點擊繼續探索。手機支援拖曳與雙指縮放。
- 可用「六度關係查詢」找現有紀錄的最短路徑；最短路徑不等於實際社交距離。
- 原先靜態圖面保留在 [legacy.html](./legacy.html)。

## 資料維護

主要資料存於 [data/network.json](./data/network.json)，包含 `meta`、`nodes` 與 `edges`。

`nodes[].id` 必須唯一，避免同名異人混淆。人物節點有 `group` 與可選 `party`：

```json
{
  "id": "示意人物",
  "label": "示意人物",
  "group": "current",
  "notes": [],
  "party": {
    "code": "UNKNOWN",
    "kind": "uncertain",
    "as_of": "",
    "source": "",
    "qualification": "尚未核對"
  }
}
```

黨籍 `code`：`KMT` 國民黨、`DPP` 民進黨、`NP` 新黨、`TPP` 民眾黨、`NPP` 時代力量、`PFP` 親民黨、`CCP` 中國共產黨、`IND` 無黨籍、`OTHER` 不適用、`UNKNOWN` 未核對。

黨籍 `kind`：`current_documented` 近期具證據、`last_documented` 最後可查紀錄、`historical_only` 僅歷史黨籍、`uncertain` 尚待核實。請勿將候選人由某政黨提名直接等同於該人現在的黨員身分。

`edges[]` 每筆均需保留 `from`、`to`、`type`、`detail`、`period`、`source`、`url`。選舉對手、批評、工作關係、同一事件與親屬必須區分；事件共現不表示私交，同一司法案件被提及不表示共同犯罪。2013年九月政爭各方指控、刑事起訴、行政調查和最終判決應明確區分。

更新資料時請保留既有人物 ID、避免重複節點，對衝突事實做來源對照，並檢查每條連線端點都存在。這是從少數條目累積的公開紀錄圖，不代表完整臺灣政治社會網絡。

## 媒體節目關係

`show_host` 是主持或代班主持、`show_guest` 是維基條目列載的常見來賓、`show_producer` 是節目製作職務。這三種連線屬於**媒體節目與人物之間的角色紀錄**，**不代表人物之間有私人關係、政治合作，或曾在同一集節目同台**。

《TVBS戰情室》條目的來賓名單依「政治評論員／各政黨」分類，但分類可能不是即時黨籍資訊。新增人物僅在缺乏其他資料時暫存該分類，並註明來源及查閱日期。此版亦將同名的民進黨人物「張志豪」和民眾黨人物「張志豪（台灣民眾黨）」分開建立 ID，後續仍應依官方資料、個人歷程檢查是否有同名混淆。


## 隨手丟維基網址的長期投遞箱

- **[📥 維基網址投遞箱：GitHub Issue #1](https://github.com/eva20011023-stack/taiwan-political-network/issues/1)**：在留言框貼上任何公開維基百科條目網址。可一則一篇、多篇，也可連續留言；不需等前一則處理完成。
- 首頁導覽也有「📥 丟維基網址」按鈕。
- 已設定每小時檢查一次投遞箱的 ChatGPT 排程；每輪最多嘗試整理兩個尚未處理的網址，實際完成速度受條目難度、工具可用性與 GitHub 權限影響。非即時處理，不應承諾一定在一小時內完成。
- [data/wiki_queue_state.json](./data/wiki_queue_state.json) 用來記錄已處理、略過及失敗的網址，避免重複合併。
- 只有確認成功提交 GitHub 才標為 `processed`；只收集公開資料，不收集私人資料，不將不相干條目強行建立政治關係。

## 維基網址投遞與進度

使用者可在 [公開維基投遞箱（Issue #1）](https://github.com/eva20011023-stack/taiwan-political-network/issues/1) 以留言方式連續提交任意維基網址。支援 `/wiki/`、`/zh-tw/` 等維基路徑。公開 [投遞進度看板](https://eva20011023-stack.github.io/taiwan-political-network/queue.html) 讀取 GitHub 留言和 `data/wiki_queue_state.json`，顯示排隊、處理中、已完成、待重試與略過。每小時的 ChatGPT 排程最多嘗試兩篇，處理時間並非保證。網址須為 repository owner `eva20011023-stack` 發送的公開留言，以免開放 Issue 遭第三人任意注入資料。開始前寫入 `processing`，推送成功後才移到 `processed`，並在 `last_run`/`last_checked_at` 記錄時間。

## 2013年監聽國會事件來源註記

2013年法務部[監聽事件調查](https://www.moj.gov.tw/2204/2795/2796/56617/)認定未有證據證明故意監聽國會總機，但查證／監督存在違失；這是行政調查結果，應與個別民事訴訟或洩密罪刑事案件分開呈現。2019年馬英九洩密案更一審無罪確定，不能誤以2018年二審有罪判決為最終判決。

## 柯建銘與特偵組擴充

柯建銘（2026年2月）從民進黨立院黨團總召交接給[蔡其昌](https://www.cna.com.tw/news/aipl/202602240166.aspx)。特偵組歷屆成員依條目以**不同屆次 hub** 記錄，避免把不同年代的檢察官錯當同事或同案辦案；檢察機關 2007 年成立、2016 年立法院三讀修正法源、2017 年 1 月 1 日裁撤，見[中央社](https://www.cna.com.tw/news/aipl/201611180190.aspx)。特偵組條目存在中立性、來源警告，案件的起訴、偵查、一審裁判及定讞不應混為一談。
